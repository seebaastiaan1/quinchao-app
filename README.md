# Quinchao App

App móvil de la Municipalidad de Quinchao — Expo + React Native + TypeScript (Expo Router).

```bash
npm install
npx expo install --fix     # alinea versiones con tu Expo Go
npx expo start             # escanea el QR con Expo Go
```

Lee `PLAN.md` (tareas) y `AGENTS.md` (reglas para agentes de IA).
